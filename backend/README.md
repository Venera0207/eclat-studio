# Сервер записи ÉCLAT STUDIO (Google Apps Script + Google Sheets)

Это «мозг» онлайн-записи: база данных записей, серверная проверка свободных
окон, защита от двойного бронирования и письма владельцу. Бесплатно, на вашей
почте Google — тот же принцип «трубы», что мы использовали в ассистенте «Атланты».

## Что умеет
- Хранит записи (таблица `bookings`), блоки интервалов (`blocks`) и журнал писем (`logs`).
- При создании записи берёт скриптовую блокировку (LockService) и **повторно**
  проверяет пересечения интервалов: два одновременных запроса на одно время не создадут две записи.
- Считает цену и пенсионную скидку **только на сервере** (браузеру не верим).
- Читает каталог услуг/мастеров/графиков из опубликованного `site-data.js` сайта
  (кеш 5 минут) — источник данных один, рассинхрона нет.
- Шлёт владельцу письмо о новой записи; сбой письма не теряет запись.
- Почасовой триггер напоминаний: утром пришлёт список записей на завтра.

## Установка (10 минут)
1. Откройте https://script.google.com → «Новый проект».
2. Удалите содержимое файла Code.gs и вставьте всё из `backend/appsscript.gs`.
3. В шапке скрипта поправьте:
   - `OWNER_EMAIL` — почта для заявок;
   - `ADMIN_TOKEN` — придумайте случайную строку (это секрет админ-операций);
   - `SITE_DATA_URL` — адрес вашего опубликованного `site-data.js`
     (например, `https://venera0207.github.io/eclat-studio/site-data.js`).
4. Сохраните проект (имя: «ÉCLAT bookings»).
5. «Развернуть» → «Новое развертывание» → тип «Веб-приложение»:
   - «Выполнять как»: **я**;
   - «Доступ»: **все**.
6. Скопируйте URL развертывания (оканчивается на `/exec`).
7. Вставьте его в `site-data.js` сайта: `SETTINGS.pipeUrl = 'https://script.google.com/macros/s/.../exec'`
   (удобно через redaktor.html, вкладка «Настройки») и закоммитьте изменение.
8. Проверка: откройте в браузере `URL/exec?action=ping` — должно прийти `{"ok":true,...}`.
9. Напоминания: в редакторе скрипта один раз выполните функцию
   `installReminderTrigger` (разрешите доступы). Отключить — `removeTriggers`.

## Важные заметки
- После замены сайта/данных кеш каталога живёт 5 минут; сброс вручную: `URL/exec?action=reload&token=...`.
- Сайт без `pipeUrl` работает в демо-режиме: записи хранятся в браузере
  посетителя, а вам всё равно уходит письмо через FormSubmit (первое письмо
   попросит подтвердить адрес — кликните ссылку один раз).
- Админ-операции (`list`, `cancel`, `block`, `unblock`) требуют `token=ADMIN_TOKEN`;
  сайт токен не хранит — админка запрашивает его у вас и держит в вашем браузере.
- Письма клиентам (SMS/e-mail подтверждения) не подключены: сайт сознательно
  собирает только имя и телефон. Архитектура готова: добавьте провайдера в
  `notifyOwner` и поле e-mail клиента в форму, когда появится задача.
