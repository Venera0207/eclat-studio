# Труба ИИ-ассистента ÉCLAT STUDIO (Google Apps Script)

Та же архитектура, что у ассистента портфолио Венеры: GLM (Z.ai) с историей
диалога, листы «Заявки» и «Диалоги», уведомления в Telegram, дайджест за день.
Фишка: системный промпт собирается из опубликованного `site-data.js` — поменяла
цену в редакторе, ассистент узнаёт её сам через 5 минут (кеш).

## Установка (10 минут)
1. https://script.google.com → «Новый проект» → вставь всё из `backend/eclat-pipe.gs`.
2. В шапке вставь свои три ключа (те же, что у портфолио):
   - `ZAI_KEY` — из твоих Заметок;
   - `BOT_TOKEN` — **рекомендую завести отдельного бота** для салона в @BotFather
     (`/newbot`, например `eclat_studio_bot`): у одного бота может быть только ОДИН
     вебхук, и салонный перехватит сообщения портфолио. Уведомления о заявках
     придут в твой личный чат (`CHAT_ID` — тот же, что у портфолио);
   - `CHAT_ID` — твой id (как в портфолио-трубе).
3. Поправь `SITE_DATA_URL` и `SITE_URL` на реальные адреса после публикации
   (до публикации ассистент всё равно знает цены: на сайте живёт локальная база,
   нейросеть подключается для сложных вопросов).
4. «Развернуть» → «Новое развертывание» → «Веб-приложение»:
   «Выполнять как»: я, «Доступ»: все → разрешить доступы.
5. Скопируй URL (`.../exec`) и впиши его в настройки сайта:
   открой `redaktor.html` → вкладка «Сайт и контакты» → поле
   «Адрес трубы ИИ-ассистента (assistantUrl)» → скачать файл → заменить в папке.
6. Проверка: в браузере открой `ЭТОТ_URL?action=chat&msg=Привет` —
   вернётся JSON с ответом нейросети. На сайте появится окошко 💬 справа внизу.
7. (Опционально) Вебхук для /start салонного бота: `ЭТОТ_URL?action=setwebhook` →
   `{"ok":true,...}`. Без вебхука бот не отвечает людям, но уведомления о заявках
   работают и так — они вебхук не требуют.
8. (Опционально) Дайджест за день: в редакторе скрипта один раз выполни
   `digestDay` через триггер: «Триггеры» → добавить → функция digestDay,
   периодичность «каждый день».

## Куда что падает
- Лист «Заявки»: дата, имя, контакт, **заявка целиком (весь диалог до контакта)**,
  источник (`eclat-assistant`); в Telegram приходит суть + хвост диалога-контекст.
- Лист «Диалоги»: **одна строка на разговор** (колонка «Весь диалог»): строка
  создаётся при первом сохранении и дообновляется по ходу разговора по SID —
  никаких обрывков и дублей. Итог: kb / slots / ai / lead.
- Заявки с формы записи сайта идут отдельно — через трубу записи
  (`backend/appsscript.gs`, лист bookings) и письмом на почту.
