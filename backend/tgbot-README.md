# Telegram-бот ÉCLAT STUDIO с кнопкой мини-приложения

Бот живёт на Google Apps Script (твоя любимая «труба»), серверов не требует.
Умеет: здороваться, отвечать про часы/адрес/цены/телефон/скидку и открывать
сайт как **мини-приложение Telegram** кнопкой «💇 Записаться онлайн».
Внутри мини-приложения имя клиента подставляется из его профиля Telegram,
а внизу экрана живёт родная кнопка Telegram «Записаться онлайн».

## Установка (10 минут)
1. В Telegram открой **@BotFather** → `/newbot` → имя: `ÉCLAT STUDIO`,
   username: например `eclat_studio_bot` → скопируй выданный токен.
2. Открой https://script.google.com → «Новый проект», вставь содержимое
   `backend/tgbot.gs`, впиши токен в `TOKEN` и проверь `MINIAPP_URL`
   (адрес сайта после публикации на GitHub Pages).
3. «Развернуть» → «Новое развертывание» → «Веб-приложение»:
   «Выполнять как»: я, «Доступ»: все → Развернуть → разрешить доступы.
4. Скопируй URL развертывания (`.../exec`) и открой в браузере:
   `ЭТОТ_URL?setwebhook=1` → ответ должен быть `{"ok":true,...}` —
   бот прописал себе вебхук и готов принимать сообщения.
5. Проверка: напиши боту `/start` → придёт приветствие с кнопкой
   «💇 Записаться онлайн» → кнопка откроет сайт внутри Telegram.

## Заметки
- Кнопка мини-приложения работает только по https-адресу — поэтому сайт
  сначала публикуем на GitHub Pages, потом подключаем бота.
- Если захочется сменить кнопку меню слева от поля ввода (вместо /start):
  BotFather → `/setmenubutton` → выбери бота → вставь `MINIAPP_URL` →
  текст кнопки, например «Записаться».
- Заявки из мини-приложения идут по той же цепочке, что и с сайта:
  труба (таблица + письмо) или резервное письмо FormSubmit.
