# ÉCLAT STUDIO — сайт парикмахерского салона с онлайн-записью

Собран Венерой Тенюшевой (и Qwen) по мастер-промту ÉCLAT STUDIO.
Стек: чистые HTML/CSS/JS (статика, живёт на GitHub Pages) + Google Apps Script
и Google Sheets как сервер записи и база данных (см. `backend/`).

## Структура
- `index.html` — главная: первый экран, бегущая строка, три направления,
  услуги с фильтрами, пенсионная скидка, мастера, о салоне, галерея с лайтбоксом,
  отзывы (честная заглушка до реальных), контакты с Яндекс-картой.
- `css/styles.css` — стиль FUTURISTIC BEAUTY × NEON LUXURY, адаптив, prefers-reduced-motion.
- `js/engine.js` — движок расписания: графики, перерывы, отпуска, буферы,
  пересечения интервалов, пенсионная скидка, валидация заявки (тестируется: `node test/engine.test.js`).
- `js/app.js` — рендер сайта и пошаговый мастер записи (8 шагов), JSONP-клиент
  сервера, письмо владельцу через FormSubmit в демо-режиме.
- `site-data.js` — ВЕСЬ контент: контакты, график, скидки, мастера, услуги,
  галерея, тексты. Правится в редакторе или руками очень осторожно.
- `img/` — фотографии (12 шт., проверены на артефакты ИИ; зеркало из styling.jpg вырезано).
- `redaktor.html` — редактор контента без кода (в стиле редактора «Атланты») — см. следующий релиз.
- `admin.html` — админка записей (там же).
- `backend/appsscript.gs` + `backend/README.md` — сервер записи и инструкция.

## Запуск локально
```
cd salon-site && python3 -m http.server 8080
# открыть http://localhost:8080
```

## Публикация на GitHub Pages
1. Создайте репозиторий (например, `eclat-studio`), загрузите содержимое папки в корень.
2. Settings → Pages → Branch: `main` / root → Save.
3. В `site-data.js` проверьте адрес/карту/контакты (по ТЗ подставлен адрес «Атланты» —
   замените на реальные данные салона через redaktor.html).
4. Подключите сервер записи по `backend/README.md` (или оставайтесь в демо-режиме).

## Демо-режим vs боевой
- Без `SETTINGS.pipeUrl`: записи хранятся в localStorage браузера посетителя,
  владельцу уходит письмо FormSubmit (нужно один раз подтвердить адрес).
- С `pipeUrl`: полноценная БД в Google Sheets, серверная проверка окон и защита
  от двойного бронирования, письма владельцу и напоминания на завтра.
