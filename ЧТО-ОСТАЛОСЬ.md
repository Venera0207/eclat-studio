# ÉCLAT STUDIO — 26.10.2026, вечер (версия 2.5): продажи вынесены ОТДЕЛЬНО

## Главное решение дня
Бот заявок, «голова» ИИ и лендинг продаж — это **личный инструмент Венеры**,
а не часть салона. Поэтому они больше не живут в трубе записи ÉCLAT:

| Было (версии 2.3–2.4) | Стало (версия 2.5) |
|---|---|
| всё в одном проекте «Эклат записи» | салон — в «Эклат записи», продажи — в новом проекте **«Венера — продажи»** |
| `backend/appsscript.gs` с ботом, ИИ и лидами | `backend/appsscript.gs` — **чистая труба салона** (записи, блоки, письма, таблицы) |
| лендинг `uslugi/index.html` в репозитории салона | репозиторий **`venera-sales`** → `index.html` + `leadpipe.gs` |
| таблица «Венера — лиды услуги» рядом с записями салона | своя таблица **«Венера — продажи»** (листы «Заявки», «Переписка с ботом», «Журнал») |

Зачем: ÉCLAT остаётся **чистым клиентским проектом** — его можно отдавать
клиенту и копировать целиком для парикмахерской, не вычищая чужой код.

## Что сделано в репозитории
- `backend/appsscript.gs` → v2.5: убраны `leadusl`, `aiTest`, бот, вебхук,
  ИИ-ключ, таблица лидов услуги; `ping` отвечает `version 2.5, project:
  eclat-bookings`; на чужие обновления Telegram труба вежливо отказывает.
- `test/pipe.test.js` → 60 проверок, включая «в трубе салона нет ничего
  продажного» (ни функций бота, ни `LEAD_BOT_TOKEN`, ни «Лиды услуги»).
- `uslugi/index.html` → заглушка-перенаправление на новый адрес.
- `backend/README.md` → разделы про бота и ИИ заменены указателем на `venera-sales`.

## Что делать НЕ нужно
❌ Заменять код в проекте «Эклат записи» больше **не нужно** — салон работает
   на развёрнутой v2.2, и трогать его незачем. (v2.5 отличается только чистотой:
   если однажды захочется развернуть и её — это косметика, не срочность.)
❌ Искать, в каком проекте лежит труба записи, тоже не нужно: бот продаж
   настраивается в **новом пустом** проекте, где перепутать нечего.

## Что осталось сделать руками
1. Создать репозиторий **`venera-sales`** на GitHub (имя важно: туда лягут
   `leadpipe.gs`, `index.html`, тесты) — 30 секунд, дальше всё сделаем сами.

4. Не срочно: заменить код в проекте ассистента на `backend/eclat-pipe.gs` (v2.2) —
   то же оформление листов «Заявки» и «Диалоги», «SID» → «Код диалога».
5. Тесты: `node test/pipe.test.js` (60) · `test/assistant.test.js` (21) ·

## «Голова» ИИ у бота заявок
Бот заявок теперь отвечает на живые вопросы нейросетью Z.ai (GLM) — **тем же
ключом**, что и ассистент салона (один ключ на два проекта).
- `var ZAI_KEY` в начале `backend/appsscript.gs` — вставить один раз;
- бот помнит последние реплики диалога (кеш скрипта, час);
- показывает «печатает…» перед ответом, чистит ответ от markdown;
- если ключа нет или Z.ai ошибся — клиент получает вежливую запасную фразу,
  а владелица всё равно видит уведомление со ссылкой «ответить»;
- если человек написал телефон — он сразу ложится в таблицу «Лиды услуги»
  с источником «чат с ботом», владелице приходит «📞 ТЕПЛЫЙ ЛИД»;
- проверка: функция `testAiHead` в редакторе или `?action=aiTest&token=…`;
- `?action=ping` честно показывает `version 2.4, ai: true`.

## Красивые таблицы (сами, без ручной приборки)
`beautify()` вызывается при каждой записи и по команде `tidyAll` / `?action=tidy`:
- колонок ровно по числу заголовков — **пустых справа не остаётся**;
- пустой хвост строк снизу подрезается, пустая вкладка «Sheet1» удаляется,
  а первый лист новой таблицы переименовывается вместо создания второго;
- заголовки **по-русски**, жирные, белым по фирменному фиолетовому `#4C2E9E`,
  шапка закреплена;
- длинные тексты — с переносом и выравниванием вверх, колонки диалогов
  560–640 px, высота строк по содержимому: текст **не обрезается**;
- чётные строки светло-сиреневые, статус «новый» выделен;
- диалоги и комментарии сохраняются **полностью** (до 40 000 знаков;
  лимит Google — 50 000), окошко чата больше не режет диалог до 2000 знаков.
