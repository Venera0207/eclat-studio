Редактор сайта ÉCLAT STUDIO

Цены, услуги, мастера, контакты и тексты — полями, без строк кода.

Как это работает: откройте файл site-data.js из папки сайта → правьте содержимое во вкладках → «Скачать файл» отдаст обновлённый site-data.js → замените им старый файл в папке сайта (или в репозитории GitHub). Черновик хранится в браузере: случайно закрыли вкладку — ничего не пропало.
